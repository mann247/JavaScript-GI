# 🎮 Rock, Paper, Scissors... SHOOT!

A simple Rock, Paper, Scissors game built with HTML, CSS, and JavaScript.

⚡️ Features
1. User Input for Rock, Pape, Scissors
2. Input Validation
3. Computer-generated random choice
4. Display Results (Win, Lose, or Tie)
5. Score Tracker
6. Reset Button to clear the score and restart the game


💻 Technology Used
1. HTML5
2. CSS3
3. JavaScript
